# Cotton House brand assets

The supplied raster reference has a deep blue house roof, two columns and curved foundation, green C, red H, green Arabic lettering and green COTTON HOUSE lettering.

- `public/brand/logo.svg`: manually reconstructed vector geometry for the house and CH mark. Lettering uses substitute system-font text, so this is a faithful design redraw, **not an exact recovery of the original typography**. Arabic lettering is kept as live text for shaping. Review the result with the owner before final production identity use.
- `public/brand/icon.svg`: geometric house/CH mark, entirely vector paths.
- `public/brand/logo.png`: transparent raster export of the SVG redraw.
- `public/brand/logo-restored.png`: AI-assisted cleaned raster interpretation of the supplied logo. This is a raster restoration, not a vector source.

The SVG redraw is the default website logo. The dashboard can replace it with an uploaded transparent PNG/WebP. Original brand structure and colors guided the navy, green and ivory website palette; the red accent stays within the mark.

`public/images/hero.jpg`, `story.jpg` and `catalog.jpg` are AI-generated illustrative editorial assets created for this demo. They are not photographs of actual Cotton House products or premises. The catalog image is a nine-panel sample sheet displayed with CSS positioning; actual uploaded product photographs are normal individual files. Each seeded product is visibly marked as a demo and no invented discount, testimonial, address or opening hours is presented as fact.
